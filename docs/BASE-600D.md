# Referência do projeto da 600D

Origem local: Sabooor ARRI, branch `sabooor-arri/fuji-camera-controls`, commit `871ab1f`, desenvolvido sobre Magic Lantern para Canon EOS 600D firmware 1.0.2.

Base upstream utilizada: https://github.com/reticulatedpines/magiclantern_simplified

O commit citado existe no projeto local da 600D; não representa uma publicação remota deste código ou um port para 5D.

Elementos a preservar como referência: moldura preta, informação real de gravação e exposição, hierarquia inspirada no mapa ALEXA 35, menu de controles reais e indicação de funções indisponíveis.

Limitações da referência: os looks Fuji são emulações criativas para prévia LCD, não perfis oficiais; não alteram H.264 nem aplicam LUT ao HDMI. As fontes DIN locais não devem ser redistribuídas sem licença. Código e recursos de terceiros devem preservar suas licenças ao serem incorporados.

O último pacote da 600D foi compilado e passou por testes no computador. A validação de um port para 5D permanece totalmente pendente. Este repositório inicial contém somente documentação própria de planejamento.
