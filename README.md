# Sabooor ARRI — Canon 5D

Projeto de adaptação do visual Sabooor ARRI para uma Canon da família EOS 5D, usando Magic Lantern como base.

**Estado: planejamento inicial. Modelo exato e firmware da câmera ainda precisam ser confirmados. Não há versão compilada ou testada para 5D.**

A referência é o Sabooor ARRI desenvolvido para a Canon EOS 600D: monitor com moldura preta e REC/STBY, navegação inspirada no mapa da ALEXA 35, controles ligados às funções reais da câmera e looks de visualização. O código específico da 600D exige revisão antes de qualquer adaptação.

## Estrutura

- `docs/ROADMAP.md`: etapas para adaptar o projeto.
- `docs/BASE-600D.md`: referência de origem e limitações conhecidas.

## Primeiro passo

Identificar modelo exato da 5D, firmware Canon, versão/base do Magic Lantern e recursos disponíveis nesse conjunto. Só depois definir o alvo de compilação e as funções suportadas.

Este projeto é independente e não é afiliado à ARRI, Canon ou Fujifilm. As marcas identificam as referências visuais e os equipamentos mencionados.
